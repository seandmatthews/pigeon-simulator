# Assets

Art, audio, fonts and models live here.

- Prefer CC0 / public-domain sources (e.g. Kenney, Quaternius, OpenGameArt CC0).
- Third-party assets go under `assets/third-party/<source>/` and **every** third-party
  file must be registered in [`CREDITS.md`](CREDITS.md) with its source URL and license.
- Godot generates `*.import` / `*.uid` files next to assets — those are committed too.
