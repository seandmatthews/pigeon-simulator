# Ames Survey — Reference Image Index

Date-stamped: 2026-11-08. Companion to `../landmarks/LANDMARKS.md` (dimensions
and locations) — this file catalogs the downloaded photographs in
`images/<cluster>/`, one row per file, plus per-cluster modeling notes.
Licensing and source URLs for every file live in each cluster's `CREDITS.md`.

Download rules honored: images saved as-is (never re-encoded), everything
under ~20 MB per file, everything CC/PD/public (a handful of all-rights-
reserved pointers are recorded in CREDITS.md as view-online links only).

Legend for "why useful": A = angle/shape reference, L = lighting/time-of-day,
M = materials/texture reference, S = signage/type reference, X = context
(what surrounds the landmark).
